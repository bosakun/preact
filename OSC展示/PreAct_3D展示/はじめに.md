# PreAct 3D展示

「PreAct_3D展示.html」をChrome・Safari・Edgeで開いてください。通信やアカウント登録は不要です。通常は開くと自動再生し、最後から最初に戻ります。動きを減らす端末設定では停止状態で開きます。

右下のボタンで、最初から再生・一時停止・次の過程・全画面表示（対応ブラウザーのみ）を切り替えられます。3D空間のドラッグで視点を変えられます。下の細い目盛りから過程を選べます。候補を押すと、その内部試行を再生します。

## 展示の内容

PreAct本体（公開コミット4439f2ca91967f5bf12eccf690cb47c98d02cbe2）を実行して取得した記録を、3Dで再生しています。候補の確認、選択、実行、結果の観測を、実際の保存データから表示します。再生時に新しい判断や実行を行うLive画面ではありません。

半透明の箱は内部で試した候補、不透明の箱は仮想空間で実行された動きです。この例では、次の一手を考え、実行後の状況から次を考えます。表示時間は説明のための再生速度で、処理時間の計測値ではありません。

限定した物理シミュレーションの例です。実機、画像からの認識、学習による上達、幅広い課題への汎用性は実証していません。保存された位置を補間し、回転と把持器は描きません。

画面の「この展示について」に説明と出典があります。「実行記録.json」は3D表示の根拠となる記録です。

## 公開URL・共有

https://bosakun.github.io/preact/ を開くと展示が自動再生します。
Zenn記事やXにはこのURLを貼ってください。GitHubのHTMLファイル画面はソース表示です。
Xのカードは静止画プレビューで、リンク先で3Dが動きます。
動きを減らす端末設定では「再生」ボタンで開始してください。

`main` のこのフォルダーを更新すると、`.github/workflows/exhibit-pages.yml` が
HTMLとプレビュー、実行記録、ライセンスだけをGitHub Pagesへ公開します。
Python API・APIキー・外部CDNは不要です。再生中に新たな判断や実行は行いません。

ローカルのHTTP確認はリポジトリルートで `python3 -m http.server 8030` を起動し、
`http://localhost:8030/OSC展示/PreAct_3D展示/PreAct_3D展示.html` を開いてください。
