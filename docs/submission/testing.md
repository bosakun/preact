# Judge Testing Instructions

Local rehearsal instructions exist in README. The final hosted URL and release are not yet
available. Complete these fields before submission: public repository, release revision,
hosted TLS URL, credentials if private, tested browser/platform, operational evidence scope.

In the release interface:
1. Run Software World. Inspect the attractive rejected repair and measured invariants.
2. Expand candidate futures; inspect engine identity, uncertainty, disagreement and gate evidence.
3. Follow the selected first action, actual outcome and prediction error; choose another decision round.
4. Run Physical World. Inspect measured robot observations, action-conditioned video, contacts,
   selected trajectory and actual simulation result, clearly distinguished from hardware evidence.
5. Compare Direct Agent and PreAct, replay stored events and inspect benchmark limitations/costs.

Access must be free and unrestricted for judges through December 15, 2026 20:00 UTC.
Archived replay supplements working access. It does not replace a functioning application.

Before final UI acceptance, run the [unfamiliar-viewer protocol](../usability-study.md).
Its five actual participant results are separate from automated browser evidence;
the prepared protocol does not satisfy the comprehension gate.
