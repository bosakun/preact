## Local footage preparation

With the actual local production service running, use
`node scripts/record_local_demo.mjs .cache/demo-footage-new` after installing frontend
dependencies and Chromium. For the separate actual local-model API, use
`PREACT_DEMO_BASE_URL=http://127.0.0.1:8134 PREACT_DEMO_EXPECT_MODE=local-model`
with the same command. The recorder checks the actual service mode, restricts its
base to literal loopback HTTP, and records live inference waiting intervals for a
clearly labeled compressed edit. Original raw footage/events remain intact; no
recorded outcome is synthesized. The recorder refuses a mismatched mode and an existing
output directory. It captures real runs, UI interaction and English scope captions;
archives run IDs/event hashes and the raw video hash. Physical exploration occupies
over 70 seconds, labeled Cartesian MuJoCo throughout. It never supplies sponsor footage,
hardware evidence, a public URL or final track qualification. Raw clips stay private
under `.cache/` for review and later assembly with actual sponsor evidence.
